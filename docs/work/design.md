## 하단 두 섹션 실사화 (11-16)
- 상담 방식 · 가입 절차를 글자 구운 포스터 2장 → **글자 없는 사진 7장 + 코드로 그린 문구**로 바꿨다
  (`Promises.tsx` 3칸, `Journey.tsx` 2×2). 문구·사진 경로는 `SITE.promises`·`SITE.journey`
- 왜: 포스터가 3D 클레이 아이콘이라 생성물 티가 났다. 둘러본 7곳 중 다모아·아정당·SK브로드밴드·LG U+ 가
  같은 계열이고 실사풍은 인터넷나무·탐나넷뿐이다
- 사진은 ChatGPT 생성(글자·얼굴·로고·지폐 없음). 원본 `docs/photo/` → `node scripts/build-photos.mjs`
  → `FE/public/photo/`. 인터넷나무·탐나넷이 쓰는 피사체 조합(탁자 위 공유기, 초록 리본 상자, 노트북 옆 헤드셋,
  계약서 서명, 현금 다발)은 피했다
- 가입 절차 카드는 사진 왼쪽을 마스크(`globals.css` 의 `.photo-fade-l`)로 풀어 글자 면과 잇는다.
  사진마다 `focus`(object-position)로 피사체가 잘리지 않게 잡는다
- 확인: 1824px · 390px 폭에서 화면으로 봤다(가로 넘침 없음). Safari 는 아직 안 봤다
- `scripts/verify-goals.mjs` 의 "메인 섹션 수 ≤ 8" 은 19개로 실패한다 — 이 중 13개는 상담폼 안
  처리방침 본문의 `<section>` 이라 이번 변경 전에도 18개로 실패하던 항목이다. 검사 쪽을 고쳐야 한다
