# 카피 — 사람 말투로

## 원칙
- 상담원이 전화로 하는 말처럼. 짧게, "저희", "~요/~드릴게요"
- 근거 없는 수치·최상급·우위 서술 금지 (CLAUDE.md 규칙 6) — "문의가 많은", "품질이 좋은" 류도 뺀다
- 문구는 `FE/lib/site-config.ts` 에서만 고친다 (통신사 상세 섹션 제목 몇 개는 컴포넌트 안)

## 바꾼 것 (대표)
| 자리 | 전 | 후 |
|---|---|---|
| 히어로 제목 | 저희 태산넷은 자신있습니다! | 인터넷 바꾸실 때, 태산넷에 한 번 물어보세요 |
| 히어로 마무리 | 편하게 물어봐주세요 | 이름이랑 번호만 남겨주세요 |
| 폼 제목 | 최적의 인터넷 요금 상담 받기 | 상담 신청 / 남겨주시면 상담사가 직접 전화드려요 |
| 통신사 섹션 | 통신사별 상품 보기 / 요금제와 약정 조건을 비교하고… | 어느 통신사 보고 계세요? / 누르시면 요금표랑 조건을 바로… |
| 통신사 부제 | 전국 커버리지와 안정적인 품질 (근거 없음) | 인터넷에 지니TV, 휴대폰까지 묶어서 보실 수 있어요 |
| 절차 제목 | 신청에서 설치 혜택 수령까지의 과정! | 신청부터 설치까지, 이렇게 진행돼요 |
| 푸터 | 어떤 상품이 맞는지 고민되시나요? | 아직 고민 중이세요? / 번호만 남겨주시면 저희가 먼저 전화드릴게요 |
| 추천 상품 | ○○ 상품 중 문의가 많은 구성입니다 | ○○에서 먼저 보시면 좋은 구성이에요 |
| 계산기 | 내 요금 계산해보기 / …바로 계산됩니다 | 우리 집 요금 계산해 보기 / …바로 나와요 |

신규: 상담 방식 3칸 — "네 곳 다 놓고 비교해 드려요 / 필요 없는 건 안 붙여요 / 돈 얘기부터 먼저 드려요"
