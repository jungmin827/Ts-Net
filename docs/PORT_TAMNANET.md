# 탐나넷 구조 이식 작업 (진행 중)

시작: 2026-09-23. 이 문서는 작업이 끝날 때까지 **계속 갱신**한다.

## 목표

탐나넷의 **레이아웃 골격**을 TS넷에 이식한다. 대상은 세 가지.

1. **메뉴바 형태** — 2단 헤더 (상단 브랜드 존 / 하단 내비 바 + 강조 CTA)
2. **와이드 캔버스 위 브랜드 로고 존** — 로고가 여백을 갖고 독립 배치
3. **동적 애니메이션 홍보 카피 존** — 풀폭 컬러 밴드에서 단어가 순차 교체되며 문장 완성

### 이식 범위 경계 (CLAUDE.md 규칙 5)

| 가져오는 것 | 가져오지 않는 것 |
|---|---|
| 레이아웃 골격, 영역 분할, 컴포넌트 배치 | 문구(카피) 원문 |
| 인터랙션 패턴(단어 교체 애니메이션, 스티키 동작) | 이미지·로고·아이콘 에셋 |
| 정보 위계, 내비 구성 방식 | CSS 코드, 색상 팔레트 |

색은 **TS넷 밝은 남색(`--brand #2b50c8`)** 기조를 유지한다. 탐나넷의 주황 기조를 따라가지 않는다.
카피는 운영자 제작분이 올 때까지 `site-config.ts` 중립 슬롯을 유지한다.

### 트랙 A 결과 요약 (검토 완료)

V1(`DESIGN_BRIEF_PROMPT.md`)이 컨셉 3종을 열어두고 디자이너에게 방향을 고르게 하는 브리프였다면,
V2는 **골격을 확정 조건으로 못박고** 디자이너의 재량을 비례·타이포·색 운용·상태 설계·모션으로 한정한다.

검토하며 확인한 핵심 사항:
- §1을 "협상 불가" 섹션으로 맨 앞에 배치. 2단 헤더는 **펼친 상태/접힌 상태 둘 다** 요구
- 애니메이션 밴드를 가장 상세히 명세 — 4슬롯(`band_lead`/`band_brand`/`band_qualifier`/`band_value`),
  체류 2.2~2.8초, 높이 고정(레이아웃 시프트 방지), 뷰포트 밖 정지, **3슬롯 축소 상태**까지 요구
- **값 슬롯이 수치일 때 조건 각주 자리(`value_condition`)를 밴드 하단에 필수 확보** —
  COPY_TEMPLATE §4 "근거 없는 대형 금액" 위험을 디자인 레벨에서 차단
- `prefers-reduced-motion` 정적 대체 시안을 별도 산출물로 요구
- 색 이탈 방지 이중 장치: §3에 globals.css 실제 토큰값 인용 + §10 금지 목록 최상단에
  "레퍼런스 주황 기조 따라가기" 명시. accent는 CTA와 밴드 값 슬롯 한 곳으로만 제한
- 카피는 전부 `{{ }}` 슬롯. 레퍼런스 문구 원문은 들어가지 않음 (규칙 5 준수 확인)

## 관찰 기록 (탐나넷 실물 — 2026-09-23 기준)

### 헤더 2단 구조
- **1단(브랜드 존)**: 상단 중앙에 로고. 로고 위에 아주 작은 태그라인 한 줄.
  우측 끝에 대표번호 버튼(아웃라인 알약형). 좌우 여백이 넓어 로고가 독립 영역을 차지한다.
- **2단(내비 바)**: 통신사 6개 + 고객센터 + 자유게시판이 가로 균등 배치.
  맨 우측에 **채워진 컬러 CTA 버튼**(신청서 작성)이 붙어 내비와 시각적으로 분리된다.

### 히어로
- 좌우 분할. **좌측 = 상담폼 카드**(흰 배경, 필드 2개), **우측 = 다크 사진 배경 위 카피 블록**.
- 우측 하단에 대표번호 라운드 버튼.

### 애니메이션 홍보 밴드
- 히어로 아래 **풀폭 컬러 밴드**(높이 약 150px).
- 단어가 하나씩 교체되며 문장을 완성: `오직` → `{브랜드}` → `최대` → `{금액}`.
- 각 단어는 화면 폭의 30~50%를 차지하는 초대형 타이포. 단어별 체류 약 2~3초.
- 밴드는 좌우 여백을 두고 라운드 없이 사각.

### 우측 스티키 사이드 레일
- 화면 우측에 고정 패널: 대표번호 / 주요 CTA 2개 / 게시판 링크 / 인증 뱃지.
- 스크롤과 무관하게 따라다닌다. (이식 여부는 트랙 B가 판단)

### 트랙 B 결과 요약 (검토 완료)

이식한 것:
- **2단 헤더** (`Header.tsx` 재작성) — 1단 브랜드 존(데스크톱, 태그라인+로고+우측 대표번호
  아웃라인 알약, 좌우 끝을 누른 가로 그라데이션 캔버스), 2단 내비 바(**이 바만 sticky**,
  6항목 가로 균등 + 바 높이를 꽉 채운 사각 accent CTA). 모바일은 기존 컴팩트 바+드로어 유지
- **홍보 밴드** (`PromoBand.tsx` 신규) — 프레임이 2.4초마다 교체되며 문장 완성.
  프레임마다 **남색 면 ↔ 밝은 남색 면**이 뒤집히고, 단어는 170ms 시차로 등장. 우측에 진행 눈금
- **맨 위로 버튼** (`BackToTop.tsx` 신규) — 사이드 레일에서 유일하게 채택한 항목

검토하며 확인한 사항:
- 밴드 컴포넌트에 **카피가 한 글자도 없다**. 전부 `PROMO_BAND` 설정값에서 온다 (`enabled:false`면 섹션 소거)
- 밴드 문구에 **지어낸 수치 없음** — "통신사 4사"처럼 검증 가능한 사실만 (규칙 6 준수)
- `prefers-reduced-motion` 시 순환을 멈추고 전체 문장을 한 줄로. 스크린리더에는 완성 문장만 읽힘
- blur 필터 0개, transform/opacity만 사용
- 밴드 높이 고정 확인 — 프레임 교체 시 레이아웃 점프 없음 (데스크톱·모바일 114px 실측)

### 사이드 레일 — 이식하지 않기로 결정

레일 4개 항목 중 대표번호·상담 CTA·게시판 링크는 하단 고정 상담바와 헤더에 **이미 있어 중복**이고,
인증 뱃지는 `SITE.business`가 전부 TODO라 지금 넣으면 **허위 표시 위험**.
비중복 항목인 "맨 위로"만 채택했다.

### 탐나넷과 의도적으로 다르게 간 지점

| # | 결정 | 근거 |
|---|---|---|
| 1 | 주황 기조 미복제 | TS넷 남색 아이덴티티 유지. accent는 CTA·강조어에만 |
| 2 | 밴드에 금액·수치 없음 | 근거 없는 수치 광고 금지 (규칙 6). 슬롯은 열어둠 |
| 3 | 밴드 위치를 **히어로 → 상담폼 → 밴드** 로 | 상담폼 카드가 히어로 위로 `-mt-10` 겹쳐 올라오는 구조라, 사이에 끼우면 흰 카드가 타이포를 덮는다 |
| 4 | 모바일은 2단 헤더 미적용 | 좁은 화면에서 2단은 세로 공간을 60px 넘게 먹는다 |
| 5 | 진행 눈금 추가 (레퍼런스엔 없음) | 없으면 문장 1/4만 깜빡이는 것처럼 읽힌다 |

### 사용자 판단이 필요한 지점

1. **데스크톱에서 스크롤 중 로고가 사라진다** — 1단만 흘려보내는 탐나넷 동작을 그대로 따른 결과.
   내비 바 좌측에 축소 로고를 fade-in 시키면 항목들이 밀려 스크롤 중 가로 이동이 생긴다.
   현재는 "레퍼런스 동작 유지 + 맨 위로 버튼"으로 둠.
2. **밴드 문구는 전부 중립 자리표시자.** 근거 확보 후 `PROMO_BAND.frames`만 교체하면 되고
   컴포넌트는 손댈 필요 없다.
