  무한 반복은 WCAG 2.2.2 대상이라 정지 컨트롤이 필요해지므로 **유한하게**
  (2회 × 2.2초 = 4.4초 < 5초) 넣었다.

**가져오지 않은 것과 이유**
- 수상·인증 섹션 2개(이미지 11장) — 보유하지 않은 실적이라 만들지 않는다.

  경쟁사 암시. 우리 차트는 **통신사 4사**를 비교한다.
- 가전제품 사은품 카탈로그 — 확정 데이터 없음. 구조(`PromoSlot`)는 열려 있다.

**레퍼런스 애니메이션 전수**: `@keyframes` 9개, 스크롤 리빌 라이브러리 **없음**(Swiper 만).

막대 성장을 갖고 CTA 모션이 없었다 — 그 빈자리를 채웠다.

**구조 검사(5개 페이지)**: h1 1개 · 제목 레벨 건너뜀 0 · 빈 alt 0 ·

## 목표 4 — 흰 면 + 쨍한 녹색 색 구조

**요구**: 탐나넷의 색 구조(완전 하얀색 + 쨍한 녹색)로 리팩토링

실측 (뷰포트 1512px, 캔버스 합성 — 그라디언트 정지점 포함):

| 분류 | 메인 |
|---|---|
| 순백 | **83.0%** |
| 아주 밝은 회색 | 47.3% |
| **진한 초록** | **0.44%** |
| 옅은 초록 틴트 | 0.28% |

흰 면 지배 구조는 레퍼런스와 같고 색면 상한(1.22%)도 지킨다.
**다만 검증 전에는 "쨍한 녹색"에서 멀어져 있었다** — 그 0.44% 의 주조가
S89%·L28% 로 어둡고, 정작 `--brand #07b040` 은 화면의 **0.003%** 뿐이었다.

원인은 전제였다. 흰 글자를 전제하는 한 4.5:1 을 맞추려면 색을 계속 어둡게 내려야 한다.
글자를 진하게 바꾸니 풀렸다 —

| 색면 | 흰 글자 | 진한 글자 |
|---|---|---|
| `#08bb45` | 2.59 ✗ | **6.88** ✓ |
| `#07b040` | 2.88 ✗ | **6.12** ✓ |

**더 쨍해졌는데 대비는 올라갔다**(4.77/6.02 → 6.88/6.12).
주조색 S89%·L28% → **S92%·L38%**.

곁들여: 공개 페이지에서 암버가 면으로 쓰이던 2곳을 초록으로 합쳤다
(같은 동작은 같은 색). 그 결과 `/kt` 색면 **전체**가 3.17% → **2.38%** 로 줄었다.

**대비 위반 0건** — 메인·상세·모바일(500px)·그라디언트 정지점 포함.

기준이 조건에 숫자로 주어지지 않았으므로 **내가 정한다.** 판단을 사용자에게
되돌리는 것은 위임받은 일을 하지 않는 것이다. 기준과 근거를 함께 적어,
동의하지 않으면 어디를 뒤집어야 하는지 보이게 한다.

## 적용한 기준

- **달성** — ① 목표가 요구한 것이 전부 존재하고 동작하며, ② 사용자가 지목한
  각 축에서 레퍼런스를 **만족하거나 넘고**, ③ 마지막 비평 라운드에서 그 영역에
  치명·높음 결함이 나오지 않았다.
- **코드 완료 / 라이브 대기** — 만들고 검증까지 끝났으나 마지막 한 단계가
  **외부 권한**을 요구한다. 품질 미달이 아니라 접근 권한 부재다.
- **미달** — 그 외. 무엇이 빠졌는지 적는다.
