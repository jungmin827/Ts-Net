**구조 검사(5개 페이지)**: h1 1개 · 제목 레벨 건너뜀 0 · 빈 alt 0 ·

## 목표 4 — 흰 면 + 쨍한 녹색 색 구조

**요구**: 탐나넷의 색 구조(완전 하얀색 + 쨍한 녹색)로 리팩토링

실측 (뷰포트 1512px, 캔버스 합성 — 그라디언트 정지점 포함):

| 분류 | 메인 |
|---|---|
| 순백 | **83.0%** |
| 아주 밝은 회색 | 47.3% |
| **진한 초록** | **0.44%** |
| 옅은 초록 틴트 | 0.28% |

흰 면 지배 구조는 레퍼런스와 같고 색면 상한(1.22%)도 지킨다.
**다만 검증 전에는 "쨍한 녹색"에서 멀어져 있었다** — 그 0.44% 의 주조가
S89%·L28% 로 어둡고, 정작 `--brand #07b040` 은 화면의 **0.003%** 뿐이었다.

원인은 전제였다. 흰 글자를 전제하는 한 4.5:1 을 맞추려면 색을 계속 어둡게 내려야 한다.
글자를 진하게 바꾸니 풀렸다 —

| 색면 | 흰 글자 | 진한 글자 |
|---|---|---|
| `#08bb45` | 2.59 ✗ | **6.88** ✓ |
| `#07b040` | 2.88 ✗ | **6.12** ✓ |

**더 쨍해졌는데 대비는 올라갔다**(4.77/6.02 → 6.88/6.12).
주조색 S89%·L28% → **S92%·L38%**.

곁들여: 공개 페이지에서 암버가 면으로 쓰이던 2곳을 초록으로 합쳤다
(같은 동작은 같은 색). 그 결과 `/kt` 색면 **전체**가 3.17% → **2.38%** 로 줄었다.

**대비 위반 0건** — 메인·상세·모바일(500px)·그라디언트 정지점 포함.

`href` 없으면 죽은 클릭 없음 · 데스크톱/모바일 분리(1512px 에서 모바일 소스는

- 가이드가 덮어쓰기 사고 증상을 "눌리거나 늘어나 보인다"고 **틀리게** 적음
