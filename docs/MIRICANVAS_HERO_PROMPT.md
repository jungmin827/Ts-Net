# 미리캔버스 AI 지시 프롬프트 — 메인 히어로 좌측 섹션

메인 히어로의 **왼쪽 열**(현재 헤드라인·서브카피 자리)을 태산넷 홍보 문구로 교체하기 위한
디자인 의뢰 프롬프트. 오른쪽에는 상담 신청 폼 카드가 그대로 붙는다.

- 아래 `여기서부터 복사` 구간을 미리캔버스 AI 입력창에 통째로 붙여넣는다.
- 문구를 고칠 때는 §4 의 텍스트 블록만 교체하고 나머지는 건드리지 않는다.
- 산출물을 받은 뒤 `FE/public/` 에 넣고 `FE/components/sections/Hero.tsx` 좌측 열을 교체한다.

> **주의** — 글자가 박힌 이미지는 수정이 불가능하고 모바일에서 잘린다
> (`FE/lib/site-config.ts` 의 기존 경고). 그래서 §9 에서 **문구 없는 배경 레이어**를
> 함께 요구한다. 최종적으로는 배경만 이미지로 쓰고 글자는 코드로 올리는 쪽을 권한다.

## 여기서부터 복사

당신은 한국 시장용 전환 중심 랜딩 페이지를 작업하는 시니어 그래픽 디자이너다.
아래 브리프를 읽고 **이미 운영 중인 웹사이트의 한 영역에 그대로 끼워 넣을 수 있는**
디자인 템플릿을 만들어 달라. 새 브랜드를 제안하는 작업이 아니라,
**확정된 디자인 시스템 안에서** 한 블록을 채우는 작업이다.

---

### 1. 이 사이트가 하는 일

**태산넷**은 인터넷·IPTV 신규 가입 상담을 받는 **인바운드 상담 접수 랜딩 사이트**다.
KT / SK브로드밴드 / LG유플러스 / KT스카이라이프 4개 통신사 상품을 비교 안내하고,
방문자가 이름과 연락처를 남기면 상담사가 전화로 가입을 진행한다.

- 사이트에서 결제·계약은 일어나지 않는다. 회원가입도 로그인도 없다.
- **유일한 성공 지표는 "이름 + 연락처 제출"이다.**
- 방문자는 이사·신축 입주·약정 만료를 앞두고 **여러 사이트를 비교 중**이며,
  이 업종에 대한 신뢰도가 기본적으로 낮다. ("번호 남기면 스팸 전화 오는 거 아냐?")
- 연령대가 넓다(20대 후반~60대). **작은 글씨와 저대비 텍스트는 실패한다.**

### 2. 당신이 만들 것이 놓이는 자리

메인 페이지 첫 화면은 **좌우 2단**이다.

```
┌─────────────────────────────────────────────────────────┐
│  헤더 (흰 배경 · 로고 · 메뉴 · 대표번호 · 주황 CTA 버튼)      │
├──────────────────────────────┬──────────────────────────┤
│                              │  ┌────────────────────┐  │
│   ★ 당신이 만들 영역 ★        │  │ 가입 상담 신청        │  │
│                              │  │ [통신사 ▾]           │  │
│   633 × 640 px               │  │ [관심상품 ▾]         │  │
│   (CSS 픽셀 기준)             │  │ [이름]  [연락처]      │  │
│                              │  │ ☐ 개인정보 동의       │  │
│                              │  │ ▓ 상담 신청하기 ▓     │  │
│                              │  └────────────────────┘  │
│                              │   흰 카드 · 초록 테두리     │
└──────────────────────────────┴──────────────────────────┘
        ← 633px →          48px          ← 439px →
```

**이것이 설계의 핵심 제약이다.**

- 오른쪽 폼 카드가 **이 페이지의 전환 장치**다. 왼쪽 영역이 시각적으로 폼을 이기면 안 된다.
  왼쪽은 "믿어도 된다"고 말하고, 클릭은 오른쪽에서 일어난다.
- 두 영역은 **같은 흰 배경 위에 나란히** 놓인다. 왼쪽만 색면 박스가 되면
  오른쪽 폼과 따로 노는 두 장의 카드처럼 보인다.
- 따라서 **배경은 반드시 순백(#FFFFFF)** 이고, **모서리 둥글림·테두리·그림자를 넣지 않는다.**
  요소만 흰 면 위에 떠 있어야 한다.

### 3. 이미 확정된 디자인 시스템 (바꾸지 말 것)

**색 — 흰 면이 기본, 초록은 포인트**

| 용도 | HEX |
|---|---|
| 배경 (고정) | `#FFFFFF` |
| 주조색 초록 | `#2F9E52` |
| 진한 초록 (제목·강조) | `#14532B` |
| 중간 초록 | `#23803F` |
| 아주 옅은 초록 (뱃지·아이콘 배경) | `#E3F5E9` |
| 가장 옅은 초록 (면 틴트) | `#F3FBF5` |
| 본문 글자 | `#1F2A24` |
| 보조 글자 | `#5F7268` |
| 경계선 | `#DCEBE1` / `#C3DDCB` |

- **큰 면적을 초록으로 칠하지 마라.** 진초록 풀블리드는 이 사이트에서 **푸터 한 곳에만** 쓴다.
  초록은 아이콘·뱃지·밑줄·작은 도형·강조 글자에만 쓴다.
- 주황 `#F7A928` 은 **버튼 전용**이다. 이 영역에 장식으로 쓰지 마라
  (오른쪽 폼의 신청 버튼이 유일한 주황이어야 눈이 거기로 간다).
- 통신사 색(KT `#E4002B` · SK `#EA5B0C` · LG `#E6007E` · 스카이라이프 `#00A0E9`)은
  **통신사 이름을 표기할 때만** 쓴다. 장식으로 쓰지 마라.

**글꼴**

- 본문·제목 모두 **Noto Sans KR**. 제목은 Black(900) 또는 Bold(700), 본문은 Regular(400).
- 포인트로 한 덩어리만 **Jua** 를 써도 된다. 단 **본문·금액·안내 문구에는 절대 쓰지 않는다.**
- 한글 제목 자간은 살짝만 좁힌다(-1% 내외). 꽉 조이면 딱딱해진다.
- 줄바꿈은 어절 단위로 끊는다(`word-break: keep-all`). 단어 중간에서 잘리면 안 된다.

**형태**

- 모서리 둥글림은 **20px(카드) / 28px(큰 패널)** 두 가지만 쓴다.
- 그림자는 쓰더라도 아주 약하게, 검정이 아니라 **진초록 섞은 그림자**로.

### 4. 넣을 문구 (글자 한 자도 바꾸지 말 것)

다음 문구가 이 영역의 주인공이다. **위계를 아래와 같이 세 단으로 나눠 조판하라.**

**① 대표 한 줄 — 가장 크게 (화면에서 제일 먼저 읽히는 문장)**

```
저희 태산넷은 자신있습니다!
```

**② 본문 — 중간 크기, 3문장**

```
고객님의 요구사항과 원하시는 상품에 맞춰
지원금과 경품을 최대한 챙겨드리려고 노력하고 있습니다.

다른 곳과 비교하고 오셔도 됩니다.
챗지피티에게 견적을 물어보고 오셔도 됩니다.

저희 직원들은 고객님과 win-win이 되는 방법을
항상 고민하고 있습니다.
```

**③ 마무리 한 줄 — 초록으로 강조, 본문보다 크게**

```
편하게 물어봐주세요
```

조판 지침:

- ①은 **자신감**이 읽혀야 한다. 느낌표가 있으니 글자 자체를 크고 굵게 가되,
  느낌표를 아이콘이나 도형으로 바꾸지 마라.
- ②의 세 덩어리는 **문단 사이 여백으로** 구분한다. 불릿·번호·구분선을 넣지 마라.
  (번호는 '순서'를 뜻하는데 이 문장들은 순서가 아니다.)
- "다른 곳과 비교하고 오셔도 됩니다 / 챗지피티에게 물어보고 오셔도 됩니다" 두 문장이
  이 카피의 **가장 강한 부분**이다. 자신감의 근거다. 이 두 줄에만
  옅은 초록 밑줄이나 옅은 초록 면(`#E3F5E9`)을 깔아 한 번 강조해도 좋다.
  단 **강조는 화면 전체에서 ③을 포함해 두 군데를 넘지 마라.**
- ③은 상담을 권하는 말이다. 오른쪽 폼 쪽을 향하도록 **영역의 아래쪽**에 둬라.

### 5. 함께 들어가야 할 요소

문구 외에 아래 3개를 작게 배치한다. 이미 사이트에서 쓰는 신뢰 문구다.

```
⚡ 접수 후 순차 연락      ⇅ 통신사 4사 조건 비교      🛡 연락처 암호화 보관
```

- 한 줄로 나란히, **본문보다 작게**, 글자색 `#5F7268`.
- 아이콘은 **선(line) 스타일**로 통일하고, 아이콘 뒤에 `#E3F5E9` 둥근 사각형 배경을 깐다.
- 이모지를 그대로 쓰지 말고 같은 뜻의 선 아이콘으로 바꿔라.

### 6. 절대 하지 말 것

이 업종 경쟁사들이 전부 하는 것들이고, 우리는 **의도적으로 반대로 간다.**

- ❌ 형광 노랑·주황 배경, 무지개 그라데이션
- ❌ 무료 3D 렌더 클립아트, 입체 워드아트, 과한 그림자·외곽선
- ❌ "최대 ○○만원", "○○% 보상", "업계 1위" 같은 **숫자나 순위 문구를 새로 만들어 넣는 것**
  (근거 없는 수치는 표시광고법 위반 소지가 있다. §4 에 없는 숫자는 한 글자도 넣지 마라.)
- ❌ 통신사 공식 로고(KT·SK·LG·스카이라이프 CI) 삽입 — 상표 사용 권한이 없다
- ❌ 사람 얼굴 스톡 사진 (상담사 실물로 오해될 수 있다)
- ❌ 말풍선·확성기·메가폰 아이콘 (소리치는 전단지처럼 보인다)
- ❌ 영역 전체를 초록으로 칠하기, 영역에 테두리나 둥근 모서리를 둘러 카드처럼 만들기

### 7. 톤

> 경쟁사가 **소리치는 전단지**라면, 태산넷은 **차분하고 정확한 상담 창구**다.

자신감은 글자 크기와 여백에서 나와야지, 색과 장식에서 나오면 안 된다.
화면이 조용할수록 "다른 곳과 비교하고 오셔도 됩니다"라는 문장이 세게 들린다.

### 8. 모바일

데스크톱에서는 좌우 2단이지만, **모바일에서는 이 영역이 위로 가고 폼이 아래로 내려간다.**
모바일에서는 가로폭이 **약 358px** 밖에 안 된다.

- 데스크톱용 그대로 축소하면 글자가 읽히지 않는다. **별도 세로형 버전을 따로 만들어라.**
- 모바일 버전은 본문 최소 **16px(CSS 기준)** 이상으로 읽히게 조판한다.
- 한 줄에 **24자를 넘기지 마라.**

### 9. 산출물 (4종을 모두 달라)

| # | 용도 | 캔버스 | 배경 |
|---|---|---|---|
| A | 데스크톱 — 문구 포함 완성본 | **1280 × 1280 px** (1:1) | 순백 `#FFFFFF` |
| B | 모바일 — 문구 포함 세로형 | **750 × 900 px** (5:6) | 순백 `#FFFFFF` |
| C | 데스크톱 — **문구 없는 배경·장식 레이어만** | 1280 × 1280 px | **투명** |
| D | 모바일 — **문구 없는 배경·장식 레이어만** | 750 × 900 px | **투명** |

- A·B 는 실제 표시 크기의 2배로 만든 것이다 (고해상도 화면 대응).
- **C·D 가 중요하다.** 글자가 박힌 이미지는 나중에 문구를 못 고치고 번역·검색도 안 되므로,
  최종 적용 시에는 배경만 이미지로 쓰고 글자는 웹 코드로 얹는다.
  C·D 에는 장식 도형·아이콘·광원만 남기고 **텍스트는 전부 빼라.**
- 모든 글자는 **안쪽 여백 8% 이상**을 두고, 캔버스 가장자리에 닿지 않게 한다.
- 파일은 PNG 로 내보낸다 (C·D 는 투명 배경 PNG).

### 10. 제출 전 자가 점검

- [ ] 배경이 순백이고, 영역에 테두리·둥근 모서리·그림자가 없는가
- [ ] 초록으로 칠한 면적이 전체의 15% 를 넘지 않는가
- [ ] 주황을 쓰지 않았는가
- [ ] §4 에 없는 문구·숫자를 추가하지 않았는가
- [ ] 강조 장치가 두 군데 이하인가
- [ ] 모바일 버전에서 본문이 16px 이상으로 읽히는가
- [ ] 문구 없는 레이어(C·D)를 함께 만들었는가

입력 글자수 제한이 있는 도구용. 전체판(위)에서 **문구와 "그렇게 하지 않으면 결과가
망가지는 제약"만** 남기고 설명·근거·산출 규격을 전부 뺐다.

문구 자체가 168자라 지시문에 쓸 수 있는 양이 230자뿐이다. 그래서 다음을 버렸다 —
사업 맥락, 방문자 특성, 톤 설명, 모바일 별도 버전, 신뢰 칩 3종, 조판 세부 지침,
산출 규격표, 자가 점검표. 이것들은 **1차 시안을 받은 뒤 후속 요청으로 보완**한다.

