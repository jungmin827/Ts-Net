# 통신사 요금표 이식 작업 (진행 중)

시작: 2026-09-28. 작업이 끝날 때까지 계속 갱신한다.

## 목표

레퍼런스(인터넷다모아)의 통신사 4사 요금표를 수집해 TS넷 `plans` 테이블 규격으로 이식한다.
현재 `plans`는 0건이라 서브페이지 4개가 전부 "요금제 준비 중"으로 뜬다.

## 원본 구조 (KT 페이지 정찰 결과)

통신사별 서브페이지에 아래 표들이 있다.

| # | 표 | 컬럼 | 비고 |
|---|---|---|---|
| 1 | 추천 인터넷/IPTV 상품 3카드 | 상품명 / 설명 / 속도 / TV / 정가 / 할인가 | |
| 2 | {통신사} 인터넷 + TV 결합 | 구성 / 총요금(월) / 할인가(월) | 6행 |
| 3 | {통신사} 휴대폰 정액 결합 | 구성 / 총요금(월) / 할인가(월) | 3행 |
| 4 | {통신사} 휴대폰 프리미엄 싱글/가족 결합 | 인원별 행렬 | 행렬 구조 |
| 5 | {통신사} 인터넷 + TV + 휴대폰 결합 | 산식 설명 | 숫자 아님 |

**각주(중요)**: `3년 약정, 휴대폰 1회선 결합 할인 기준, VAT포함가`
→ `contract_months = 36`, 표시 금액은 VAT 포함. 이 전제를 화면에 반드시 함께 노출한다.

**사은품(현금 지원금) 컬럼은 없다.** → `gift_amount`는 전부 `null`로 둔다.
근거 없는 사은품 금액을 만들어 넣지 않는다 (CLAUDE.md 규칙 6).

## 선결 과제 (블로커)

1. **Supabase 연결 불가** — 풀러가 `tenant/user not found` 반환.
   무료 플랜 프로젝트 일시정지로 추정. 대시보드에서 재개(Resume)해야 한다.
2. **anon key 미설정** — `FE/.env.local`의 `NEXT_PUBLIC_SUPABASE_ANON_KEY`가 비어 있어
   DB에 데이터를 넣어도 사이트가 읽지 못한다.

→ 둘 다 해결 전까지는 **시드 SQL이 최종 산출물**이고, 화면 반영은 보류된다.

## 데이터 출처 표기 (중요)

이 수치는 **2026-09-28 시점 레퍼런스 사이트에서 수집한 타사 게시 가격**이다.
- 통신사 표준 요금과 결합 할인에 기반하지만, **우리 계약 조건과 일치한다는 보장이 없다.**
- 런칭 전 **각 통신사와의 실제 계약 조건으로 반드시 재검증**해야 한다.
- 검증 전까지 화면에는 `PLAN_DISCLAIMER`(조건에 따라 달라질 수 있음)가 항상 함께 노출된다.

| 휴대폰 프리미엄/가족 결합 (KT·SK·LG) | 인원별 행렬 구조라 "1행=1상품" 모델에 대응 불가. 원문은 추출 JSON의 `premium_family_raw`에 보존 |

## 2차 — 요금 계산기 (2026-09-28)

레퍼런스처럼 **속도·TV·휴대폰을 고르면 요금이 즉시 합산되는 계산기**를 붙였다.

### 스키마 확장 (`002_plans_list_fee_tv_option.sql`)

| 컬럼 | 용도 |
|---|---|
| `list_fee` | 할인 전 총요금. 그동안 description 문자열에 묻혀 있었다 |
| `tv_option` | TV 구성명. 계산기의 TV 축 |

두 값은 `"총요금 50,600원 → 결합 할인가"` 같은 문장에 섞여 있어 화면에서 쓸 수 없었다.
additive 변경이라 기존 컬럼·행은 그대로다.

### 계산기 동작

- 축은 **결합표 행(sort_order ≥ 10)** 에서만 만든다. 추천 카드는 같은 구성의 별칭이라
  축에 넣으면 같은 조합이 두 번 잡힌다.
- **표에 없는 조합은 계산하지 않는다.** 보간해서 숫자를 만들면 근거가 없어지므로,
  "상담 시 안내" 로 대체한다 (CLAUDE.md 규칙 6).
- 휴대폰은 선택 사항이고, 고르면 결합표 요금에 더한다.
- 검증: KT 100M + TV모든G(45,100) + 5G 슬림 4GB(24,750) = **69,850원**, DB 값과 일치.

### 원본 오타 1건 정규화

SK 5행 구성명이 `TV스탠다드`가 아닌 `T스탠다드`로 적혀 있다.
**상품명(`name`)은 원문 그대로 보존**하고, 계산기 축으로 쓰는 `tv_option`만
`TV스탠다드`로 정규화했다. 정규화하지 않으면 선택기에 깨진 옵션이 하나 더 뜬다.
(표에 그대로 두는 것과 선택지로 노출하는 것은 다르다고 판단)

### 화면 반영

- `PlanCalculator` 신규 — 서브페이지에서 추천 카드보다 **먼저** 나온다.
  찾아보기 전에 "내 경우 얼마인지"를 먼저 답해주는 순서
- `PlanCards` — 요금 띠에 정가 취소선 → 할인가 대비 추가
- `PlanTable` — `총요금(월)` / `할인가(월)` 두 컬럼으로 분리 (레퍼런스와 동일)
