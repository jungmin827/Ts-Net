# UI 이식 로그 — 탐나넷 골격 → TS넷 (트랙 B)

작업 시작: 2026-09-23. `docs/PORT_TAMNANET.md`의 이식 목표를 실제 FE 코드로 옮기는 과정 기록.
**관찰 → 구현 → 검증**을 반복하며 매 회차를 아래에 누적한다.

환경: dev 서버 `PORT=3100 npm run dev`, 데스크톱 1440 / 모바일 뷰포트로 교차 확인.

## 1회차 — 골격 3종 1차 이식

### 관찰 (탐나넷 실물, 1440)

**헤더 2단**
- 1단 브랜드 존: 흰 면, 높이 약 105px. 로고가 왼쪽에 놓이고 좌우로 여백이 넓다.
  우측 끝에 대표번호 **아웃라인 알약 버튼**. 이 영역은 스크롤하면 그냥 흘러간다.
- 2단 내비 바: 높이 약 46px. 메뉴 항목이 컨테이너 폭 안에서 **가로 균등 배치**되고,
  맨 우측에 **채워진 컬러 CTA**가 바 높이를 꽉 채운 사각형으로 붙는다(라운드 없음).
  스크롤하면 **이 바만** 상단에 고정된다. 즉 "브랜드 존은 흘려보내고 내비만 sticky".

**애니메이션 홍보 밴드**
- 히어로 아래, 높이 약 145px. 프레임이 순차 교체되며 한 문장이 완성된다.
- 관찰된 프레임 흐름: 단어 덩어리 1장 → 브랜드명 포함 구 1장 → 숫자 1장 → 마무리 단어 1장.
- **프레임마다 배경 면 색이 뒤집힌다** (컬러 면 ↔ 흰 면). 이게 리듬을 만드는 핵심.
- 글자는 화면 폭의 30~50%를 차지하는 초대형. 등장 시 확대·모션블러 느낌.
- 프레임당 체류 약 2~3초.

**우측 스티키 사이드 레일**
- 대표번호 / CTA 2개 / 게시판 링크 / 인증 뱃지 / 맨위로 버튼.

### 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 2단 헤더 | 이식 (데스크톱 `lg` 이상만) | 좁은 화면에서 2단을 그리면 세로를 60px 넘게 먹는다. 모바일은 기존 컴팩트 바+드로어 유지 |
| sticky 범위 | **2단 내비 바만** sticky, 1단은 흘려보냄 | 탐나넷 동작과 동일. 브랜드 존까지 붙이면 스크롤 중 상단을 120px 점유 |
| CTA 버튼 | 바 높이를 꽉 채운 **사각** 블록, `--accent` | 골격은 그대로 가져오되 색만 TS넷 액센트로. 주황 기조 복제 아님 |
| 홍보 밴드 색 | **남색 면 ↔ 밝은 남색 면** 교차 | 탐나넷의 "면이 뒤집히는" 구조만 가져오고, 주황/흰 대비는 쓰지 않음 |
| 밴드 문구 | `site-config.ts`의 `PROMO_BAND` 설정값 | 컴포넌트에 카피를 한 글자도 두지 않는다. 운영자가 배열만 교체 |
| 밴드 모션 | `transform`+`opacity` 만 | 초대형 글자에 blur 필터를 걸면 합성 비용이 큼 (프로젝트 성능 제약) |
| 사이드 레일 | **이식 안 함** (아래 별도 항목) | 하단 고정 상담바와 기능이 중복 |

#### 사이드 레일을 이식하지 않은 근거

탐나넷 레일의 구성요소를 TS넷 현재 화면과 1:1로 대조했다.

| 레일 항목 | TS넷 현황 | 판정 |
|---|---|---|
| 대표번호 | 헤더 1단 알약 버튼 + 하단 상담바 좌측 + 히어로 CTA | 3중 중복 |
| 상담 CTA | 하단 상담바(데스크톱은 **한 줄 폼 자체**가 상시 노출) | 중복. 레일 버튼은 폼보다 약한 장치 |
| 게시판 링크 | 헤더 2단 내비에 상시 노출 | 중복 |
| 인증 뱃지 | 사업자 증빙 미확보 (`SITE.business`가 전부 TODO) | 지금 넣으면 허위 표시 위험 |
| 맨 위로 | 없었음 | **유일한 비중복 항목** |

탐나넷은 하단 고정 바가 없어서 레일이 유일한 상시 전환 수단이다. TS넷은 그 역할을
하단 상담바가 이미, 그것도 더 크게(입력 필드가 열린 한 줄 폼으로) 하고 있다.
레일을 통째로 이식하면 화면 우측에 같은 버튼이 두 벌 생기고, 1440에서
`max-w-6xl` 콘텐츠 우측 가장자리와 겹친다. → **레일 전체는 버리고 "맨 위로" 하나만** 채택.
(`components/ui/BackToTop.tsx`. 하단 상담바 4.5~5.5rem, Turnstile 슬롯 `bottom-24`를 모두
피해 `bottom-[11rem]`에 띄운다.)

### 구현

| 파일 | 내용 |
|---|---|
| `FE/components/sections/Header.tsx` | 2단 구조로 재작성. 1단 브랜드 존(데스크톱) / 2단 내비 바(sticky) / 모바일 컴팩트 바. 드로어는 기존 그대로 |
| `FE/components/sections/PromoBand.tsx` | **신규**. 프레임 순차 교체 밴드 |
| `FE/components/ui/BackToTop.tsx` | **신규**. 레일에서 건진 단 하나 |
| `FE/lib/site-config.ts` | `SITE.tagline`, `PROMO_BAND`(+`PromoWord`/`PromoFrame` 타입) 추가 |
| `FE/app/globals.css` | `--animate-promo-word` + `@keyframes promo-word` 추가 |
| `FE/app/(site)/layout.tsx` | `BackToTop` 마운트 |
| `FE/app/(site)/page.tsx` | `PromoBand` 삽입 |

### 검증 (1440 / 모바일)

- 2단 헤더 정상. 스크롤 시 1단이 흘러가고 2단만 상단 고정 + 그림자. 의도대로.
- 밴드 4프레임이 남색↔밝은면으로 교차하며 순환. 단어 시차 등장 확인.
- 모바일: 브랜드 존 숨김, 기존 컴팩트 바·드로어·하단 상담바 그대로. 밴드는 높이 112px로 접힘.

### 발견한 문제

1. **밝은 면 프레임의 세로 격자가 너무 튄다.** 선이 글자보다 먼저 읽혀 표처럼 보였다.
2. 밴드 문장이 뚝뚝 끊겼다 — `한자리에서 비교` / `확인하고 신청하세요`.
3. 헤더 CTA가 `/#consult`라 통신사 서브페이지에서 메인으로 튕겼다.
   (서브페이지도 `id="consult"`를 갖고 있어 상대 앵커면 충분)
4. 브랜드 존 태그라인 자간 `0.18em`이 국문에서 과하게 벌어졌다.

## 2회차 — 1회차 문제 수정

### 구현

| 문제 | 수정 |
|---|---|
| 밝은 면 격자 | 격자를 **남색 면에서만** 렌더 (`isBrand &&`) |
| 문장 흐름 | `한자리에서 비교하고` / `확인 후 신청하세요` 로 교체 (설정값 수정만) |
| 헤더 CTA 앵커 | `/#consult` → `#consult` (메인·서브페이지 모두 앵커 보유) |
| 태그라인 자간 | `0.18em` → `0.11em` |

### 검증

- 밝은 면이 깨끗해지고 타이포가 앞으로 나온다.
- 밴드 전체 문장: `인터넷 · TV 가입 / 통신사 4사 조건을 / 한자리에서 비교하고 / 확인 후 신청하세요`
  — 4프레임이 이어져 한 문장이 된다.

## 3회차 — 밴드 존재감 / 브랜드 존 캔버스 / 중간 폭 검증

### 관찰 (로컬 1440 · 1024)

1. **밝은 면 프레임이 밴드로 안 읽힌다.** 위아래가 흰 섹션이고 밴드도 `--brand-soft`(거의 흰색)라
   경계가 사라졌다. 탐나넷은 밴드 주변이 회색 배경이라 흰 밴드가 성립하지만 우리는 아니다.
2. **브랜드 존이 그냥 흰 여백**이었다. "와이드 캔버스 위 로고 존"이라기보다 빈 줄에 가깝다.
3. 1024에서 내비 6항목 + CTA 가 줄바꿈 없이 들어가는지 미확인이었다.
4. 통신사 서브페이지에서 2단 헤더가 정상인지 미확인이었다.
5. 밴드가 한 번에 문장의 1/4만 보여주는데, **그게 연작임을 알리는 단서가 없다.**
   탐나넷도 마찬가지지만, 우리 밴드는 체류 2.4초라 지나가던 사람은 그냥 깜빡임으로 읽는다.

### 구현

| 항목 | 처리 |
|---|---|
| 밝은 면 존재감 | 그라데이션을 `brand-light → brand-soft → brand-light` 로 바꾸고 방사형 광원 0.10→0.16. 추가로 **밝은 면일 때만 `border-y`** |
| 브랜드 존 캔버스 | 좌우 끝을 `--brand-soft` 로 눌러주는 가로 그라데이션 + 로고 뒤 광원 강화, 세로 여백 `py-6`→`py-7` |
| 진행 눈금 | 밴드 우측에 프레임 수만큼 작은 눈금. 현재 프레임만 길어진다. `sm` 미만·모션최소화에서는 숨김 |

### 검증

- 1440: 남색 면 ↔ 밝은 면 교차가 또렷해지고, 프레임이 바뀌어도 밴드 높이가 동일(레이아웃 점프 없음).
- 1024: 내비 6항목 + CTA 한 줄 유지, 줄바꿈 없음.
- `/kt` 서브페이지: 2단 헤더 정상. 활성 항목(KT) 밑줄이 서브 히어로의 통신사 컬러 스트라이프와 맞닿는데,
  겹치지 않고 위아래로 나란히 놓여 오히려 통신사 색과 브랜드 색이 같이 읽힌다. 그대로 둔다.
- 모바일(≈500 뷰포트): 브랜드 존 숨김, 기존 컴팩트 바·드로어 유지. 밴드 높이 112px, 눈금 숨김.

### 남은 판단거리 (사용자 확인 필요)

1. **데스크톱에서 스크롤 중 로고가 사라진다.** 1단만 흘려보내는 탐나넷 동작을 그대로 따른 결과다.
   홈 링크를 항상 두고 싶으면 내비 바 좌측에 작은 로고 마크를 fade-in 시키는 방식이 있는데,
   그러면 항목들이 밀려 스크롤 시 가로 이동이 생긴다. 현재는 "레퍼런스 동작 유지 + 맨위로 버튼"으로 뒀다.
2. **밴드 문구는 전부 자리표시자다.** 수치·혜택을 넣으려면 근거자료 확보 후
   `PROMO_BAND.frames` 만 교체하면 된다 (컴포넌트 수정 불필요).
3. `PROMO_BAND.enabled = false` 로 두면 밴드 섹션이 통째로 사라진다.

## 탐나넷과 **의도적으로 다르게** 간 부분

| # | 탐나넷 | TS넷 | 이유 |
|---|---|---|---|
| 1 | 주황 기조. 밴드도 주황/흰 교차 | 남색 기조. 밴드는 남색/밝은남색 교차, 액센트는 CTA·강조어에만 | 브랜드 아이덴티티 유지 (`docs/DESIGN.md`). 색 팔레트 복제 금지 |
| 2 | 밴드에 금액 수치("최대 N만원") | **수치 없음**. 사실 서술만 | CLAUDE.md 규칙 6 — 근거 없는 수치 광고 금지. `PROMO_BAND`에 슬롯만 열어둠 |
| 3 | 단어 등장에 모션블러 | `transform`+`opacity` 만 | blur 필터 금지 (모바일 성능). 같은 "훅 들어오는" 인상을 필터 없이 냄 |
| 4 | 밴드가 히어로 **바로 아래** | 히어로 → 인라인 상담폼 → **밴드** | 기존 구조상 상담폼 카드가 히어로 위로 `-mt-10` 겹쳐 올라온다. 그 사이에 밴드를 끼우면 흰 카드가 밴드를 덮어 타이포가 잘린다. 퍼스트뷰의 전환 장치(폼)가 밴드보다 우선 |
| 5 | 밴드가 컨테이너 폭 안에 갇힘 | **풀블리드** | 요구사항이 "풀폭 밴드". 글자만 `max-w-6xl`에 정렬해 히어로 좌측 기준선과 맞춤 |
| 6 | 내비 6개 통신사 + 고객센터 + 자유게시판 | 통신사 4개 + 가입후기 + 정보공유 | 취급 통신사가 4사 (CLAUDE.md) |
| 7 | 우측 스티키 레일 풀세트 | 레일 없음, "맨 위로"만 | 위 "사이드 레일" 항목 참조 |
| 8 | 2단 헤더가 모바일에서도 유지 | 모바일은 기존 컴팩트 바 + 드로어 | 세로 공간 절약. 기존 구현을 없애지 않는다는 작업 조건 |
| 9 | 모션 최소화 대응 없음 | `prefers-reduced-motion` 이면 **순환 정지**, 전체 문장 1줄 노출 | 자동 순환 자체가 모션이라 duration만 0으로 줄이는 걸론 부족 |
| 10 | 밴드가 스크린리더에 쪼개져 읽힘 | 완성 문장 1줄을 `sr-only`로 제공, 애니메이션 레이어는 `aria-hidden` | 접근성 |
| 11 | 밴드에 진행 표시 없음 | 우측에 프레임 눈금 추가 | 문장이 4장에 나뉘어 있다는 걸 알려야 "깜빡임"으로 안 읽힌다 |

## 최종 검증

| 항목 | 결과 |
|---|---|
| `npx tsc --noEmit` | 오류 0 |
| `npx next lint --max-warnings=0` | 경고 0 |
| `npm run build` | 성공 |
| 데스크톱 1440 / 1024 | 헤더 2단·밴드·맨위로 정상 |
| 모바일 뷰포트 | 컴팩트 바 + 드로어 + 하단 상담바 기존 그대로, 밴드 축소 렌더 |

### 건드리지 않은 것

- `components/forms/StickyConsultBar.tsx` (하단 고정 상담바) — 손대지 말라는 조건 준수
- Turnstile 마운트 지점 — 기존대로 **보이는 위치에 하나만**. 새로 추가한 컴포넌트는
  Turnstile 을 전혀 쓰지 않으며, `BackToTop` 위치를 `bottom-[11rem]` 로 잡아 위젯 슬롯(`bottom-24`)과 겹치지 않게 했다
- `blur` 계열 필터 — 신규 코드에 단 하나도 없음 (전부 radial-gradient / transform)
