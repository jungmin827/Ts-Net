# TS-net 디자인 시안

작성일: 2026-09-15. 레퍼런스 2곳을 직접 열람해 구조를 분석하고 TS-net 시안을 정리한 문서.

## 원칙 (CLAUDE.md 규칙 5·6 준수)

- 레퍼런스에서 **구조·기능 패턴만** 참고한다. 문구·이미지·CSS는 복제하지 않는다.
- **카피·홍보 템플릿은 운영자(사용자)가 직접 제작해 제공할 예정** — 그전까지
  `FE/lib/site-config.ts`의 중립적 플레이스홀더를 유지하고, 템플릿이 오면 그 파일만 교체한다.
- 레퍼런스의 과장성 문구(차액 120% 보상, 최대 220만원 등)는 채택하지 않는다.
  수치성 문구는 근거 확보 후 설정값으로만 넣는다.

## 레퍼런스 A — 인터넷다모아 (xn--t60bv5ao1noylqucs0u.com)

### 메인 구조 (위→아래)
1. **헤더**: 로고 / 통신사 4메뉴(KT·SK·LG·스카이라이프) / 후기게시판 / 정보공유 / 대표번호(강조)
2. **히어로**: 프로모션 헤드라인 + 해시태그성 서브카피 + 3D 그래픽. 밝은 단색(옐로) 배경
3. **스티키 퀵상담 바**: 화면 상단에 고정 — `대표번호(크게) | 관심상품 select | 이름 | 연락처 | 동의 체크 | 상담요청 버튼`이 한 줄. 접기 화살표 있음. **모든 페이지에서 유지됨**
4. **상담폼 + 실시간 신청현황 2컬럼**: 좌측 상담폼(동의 약관 전문을 스크롤 박스로 노출), 우측 실시간 테이블(날짜/통신사 로고/`김**`/신청현황/사은품 5컬럼, 8행)
5. **차별점 3카드**: 3D 아이콘 + 제목(키워드 컬러 강조) + 3줄 설명
6. **가입절차 5스텝**: 원형 아이콘 + 화살표(→) 연결, 각 스텝에 소요시간 서브텍스트
7. **후기 그리드**: 썸네일 + 제목 + 별점 + 본문 발췌 + 날짜, "후기 보러가기" 링크
8. **푸터**: 사업자 정보 6종 + 약관/개인정보 모달 링크 + 대표번호 재노출

### 서브페이지 구조 (KT 기준, 4사 공통 템플릿)
1. **서브 히어로**: 통신사명 + "상품, 혜택, 요금을 직접 확인" 서브카피 + 상담 CTA. 통신사 브랜드 컬러로 포인트
2. **인터랙티브 요금 계산기**: 인터넷 속도(미포함/100M/500M/1G) · TV(채널 규모별) ·
   휴대폰 결합 · 결합 인원을 토글로 선택 → 우측 **sticky 요금 카드**에 총 요금 실시간 합산
3. **추천 상품 3카드**: 상품명 + 구성 아이콘 + 정가(취소선)→할인가 + 상담 CTA
4. **결합 요금표 테이블 4종**: 인터넷+TV / 휴대폰 정액 결합 / 프리미엄 싱글·가족 / 3결합.
   컬럼: 구성 | 총요금(월) | 할인가(월)
5. 공통 푸터 + 스티키 퀵바

### 채택 포인트
- 스티키 퀵상담 바 (전 페이지 공통) — 전환의 핵심 장치
- 서브페이지 = 브랜드 히어로 + 추천 3카드 + 요금표. 요금 계산기는 2차 구현 후보
- 실시간 현황의 5컬럼 테이블 형태 (단, **우리는 실데이터만** — 이미 구현됨)

7. **통신사별 종합 혜택 6카드 그리드**: 카드마다 통신사 로고 + 혜택 요약 리스트 +

8. **신뢰 섹션**: 공식 인증서·사업자등록·통신판매신고 증빙 이미지 나열 ("공식 인증받은 영업점")

## TS-net 시안

### 컬러 시스템 — "밝은 남색" 아이덴티티

레퍼런스들이 옐로/오렌지 계열인 것과 달리, TS-net은 **밝은 남색(bright navy)**을 주조색으로.
CTA는 보색 계열 주황으로 대비(업계 관행상 전환 버튼은 난색이 유리).

| 토큰 | 값 | 용도 |
|---|---|---|
| `--brand` | `#2B50C8` | 주조색 (밝은 남색) — 헤더 로고, 버튼, 강조 텍스트 |
| `--brand-dark` | `#1D379B` | 호버, 히어로 그라데이션 딥엔드, 모바일 전화 버튼 |
| `--brand-light` | `#EAF0FF` | 섹션 배경 틴트, 뱃지 배경 |
| `--accent` | `#F59E0B` | CTA(상담 신청)·사은품 강조 |
| `--carrier-*` | KT `#E4002B` / SK `#EA5B0C` / LG `#E6007E` / SKYLIFE `#00A0E9` | 통신사 뱃지·서브 히어로 (공식 가이드 재확인 필요) |

모든 값은 `FE/app/globals.css` 한 곳에서만 관리.

### 메인 페이지 (현재 구현 + 보강)

```
헤더 (sticky, 흰 배경 + 남색 로고·CTA)
히어로 — 남색 그라데이션. ⟵ 운영자 제작 카피·이미지 대기
[보강] 스티키 퀵상담 바 — 다모아 패턴. 스크롤 시 상단 고정 한 줄 폼
인라인 상담폼 (구현됨) — [보강] 탐나넷처럼 히어로 옆 2컬럼 배치 검토
실시간 신청현황 (구현됨 — 실데이터, 5건 미만 미출력)
[보강] 통신사 4카드 허브 — 탐나넷 패턴. 브랜드 컬러 코딩, 서브페이지 진입점
차별점 4카드 (구현됨)
가입절차 5스텝 (구현됨)
후기 슬라이더 (구현됨)
[추가 예정] 신뢰 섹션 — 사업자 증빙 확정 후
푸터 (구현됨)
플로팅 퀵상담(데스크톱) / 모바일 하단바 (구현됨)
```

### 통신사 서브페이지 `/[carrier]` (다음 구현 대상)

```
1. 서브 히어로 — 해당 통신사 브랜드 컬러 그라데이션 + 통신사명 + 상담 CTA
2. 추천 상품 3카드 — plans 테이블에서 sort_order 상위 3개 (카드: 상품명/속도/월요금/사은품/CTA)
3. 요금표 테이블 — plans 테이블 category별 (INTERNET / TV / BUNDLE) 렌더링
   컬럼: 상품명 | 속도 | 월요금 | 약정 | 현금 사은품
4. 제휴카드 할인 안내 + 상세 모달 (SPEC §1.2)
5. 하단 상담폼 — LeadForm에 defaultCarrier 프리셋 (구현돼 있는 prop 사용)
6. 공통 셸 (헤더/푸터/퀵폼/하단바 자동 적용 — (site) 레이아웃)
```

요금 계산기(다모아 패턴)는 **2차 구현 후보** — plans 데이터가 쌓이고 결합 정책이 정리된 뒤.

### 타이포·톤

- Noto Sans KR (구현됨). 헤드라인 900, 본문 400, 숫자 강조 700
- 금액·혜택 숫자는 `--accent` 또는 `--brand`로 강조하되, 근거 없는 수치는 쓰지 않는다
- `word-break: keep-all` (구현됨) — 한국어 조사 단위 줄바꿈

### 구현 우선순위

- [ ] 브랜드 토큰을 밝은 남색 팔레트로 교체 (`globals.css`)
- [ ] 통신사 서브페이지 4종 (위 시안 순서)
- [ ] 메인에 통신사 4카드 허브 섹션 추가
- [ ] 스티키 퀵상담 바 (스크롤 임계 후 노출)
- [ ] 운영자 카피 템플릿 수신 → `site-config.ts` 교체
- [ ] 신뢰 섹션 (증빙 자료 수신 후)
