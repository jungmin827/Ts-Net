# 홍보 이미지 삽입 가이드 (운영자용)

외부 디자인 툴(미리캔버스 등)에서 만든 홍보 이미지를 **코드 수정 없이** 사이트에 꽂는 방법.

## 1. 파일을 넣는다

`FE/public/promo/` 아래에 둔다. 파일명은 영문·숫자·하이픈만.

```
FE/public/promo/gift-2026q4.png       ← 데스크톱용
FE/public/promo/gift-2026q4-m.png     ← 모바일용 (글자가 있으면 필수)
```

> **데스크톱 한 장으로 때우지 말 것.** 모바일 가로폭은 약 358px 이다.
> 2240px 짜리를 줄이면 배율이 16%가 되어, 원본 56px 글자가 9px 로 찍힌다.
> 글자가 박힌 이미지는 반드시 모바일용을 따로 만든다.

## 2. 설정값 한 항목을 채운다

`FE/lib/site-config.ts` 의 `PROMO_IMAGES` 배열에 추가한다. **이 파일만 고치면 된다.**

```ts
export const PROMO_IMAGES: PromoImage[] = [
  {
    id: "gift-2026q4",
    slot: "afterPriceCompare",
    desktop: "/promo/gift-2026q4.png",
    mobile: "/promo/gift-2026q4-m.png",
    width: 2240,  height: 900,
    mobileWidth: 750, mobileHeight: 900,
    alt: "4분기 가전 사은품 안내 — 지급 조건은 상담 시 안내해 드립니다",
    href: "#consult",
    enabled: true,
  },
];
```

### 넣을 수 있는 위치 (`slot`)

메인 페이지의 실제 섹션 순서는 이렇습니다 (**굵은 글씨가 슬롯**) —

> 히어로 → **afterHero** → 홍보 밴드 → **afterPromoBand** → 실시간 현황 →
> 통신사 4카드 → 통신사 비교표 → 요금 비교표 → **afterPriceCompare** →
> 가입 과정 → **afterJourney** → 상담 안내 → 후기 → 자주 묻는 질문 →
> 개인정보 안내 → **beforeFooter** → 푸터

| 값 | 바로 위에 오는 섹션 |
|---|---|
| `afterHero` | 퍼스트뷰(상담폼) |
| `afterPromoBand` | 홍보 밴드 |
| `afterPriceCompare` | **요금 비교표** — 통신사 4카드 바로 밑이 아닙니다 |
| `afterJourney` | 가입 과정 4단계 |
| `beforeFooter` | **개인정보 안내** — 후기 바로 밑이 아닙니다 |

같은 슬롯에 여러 장을 넣으면 배열 순서대로 세로로 쌓인다.

### 각 필드

- **`width` / `height`** — 원본 픽셀 크기를 **정확히** 적는다. 틀리면 이미지가
  늦게 뜰 때 아래 내용이 밀려 올라갔다 내려오는 현상(레이아웃 시프트)이 생긴다.
- **`mobile`** — 모바일 전용 소스. **글자가 박힌 이미지라면 반드시 따로 넣는다.**
  데스크톱 한 장(2240px)을 358px 폭으로 줄이면 본문이 9px 가 되어 읽히지 않는다.
  비워두면 데스크톱 소스를 그대로 쓴다.
- **`mobileWidth` / `mobileHeight`** — 모바일 소스의 원본 픽셀 크기.
  생략하면 데스크톱 값을 쓰는데, 두 장의 비율이 다르면 그만큼 레이아웃이 튄다.
- **`alt`** — 이미지 안의 핵심 문구를 그대로 옮긴다. 화면을 못 보는 사용자와
  검색엔진이 읽는 유일한 단서다. **비워두지 말 것.**
  (빈 문자열이면 화면에 아예 렌더하지 않고 콘솔에 오류를 남긴다.
   `node FE/scripts/verify-goals.mjs` 의 G5 에서도 걸린다 — 배포 전에 잡힌다.)
- **`href`** — 보통 `"#consult"` (퍼스트뷰 상담폼으로 이동). 생략하면 못 누르는 그림이 된다.
  누를 수 있게 하면 링크 이름 끝에 "— 상담 신청하러 가기" 가 자동으로 붙는다.
- **`enabled`** — `false` 로 두면 파일을 지우지 않고도 내릴 수 있다. 시즌 프로모션에 쓴다.

## 3. 확인한다

```
cd FE && npx next dev --turbopack -p 3100
```

데스크톱(1440px)과 모바일(390px) 둘 다에서 본다. 모바일은 브라우저 개발자도구의
기기 모드로 확인한다.

## 이미지를 교체할 때 — 파일명을 바꿀 것

**같은 파일명으로 덮어쓰지 마세요.** 브라우저와 Next 이미지 최적화 캐시가 URL 로
판단하기 때문에, 경로가 같으면 **이전 이미지를 계속 내보냅니다.**
그런데 `width`/`height` 설정값은 새 크기로 바뀌어 있어 **자리표시자만 틀린 비율**로 잡힙니다.

**이미지가 눌리거나 늘어나 보이지는 않습니다.** 찌그러짐을 기준으로 점검하면
영원히 아무 이상도 못 봅니다 — 이미지에 `h-auto` 가 걸려 있어 로드가 끝나는 순간
높이가 실제 파일 비율로 다시 계산되기 때문입니다.

**실제 증상은 하나뿐입니다 — 스크롤 중 아래 내용이 크게 튀어오릅니다.**
(실측: `2240×938` 이미지를 `width:1000 height:2000` 으로 적어 두면
자리표시자 높이 2240px → 로드 후 469px, **1771px 점프**)

실제로 겪은 사례: `check-three.png` 를 920px → 938px 높이로 다시 만들었더니,
설정은 938 인데 화면에는 920 짜리 옛 이미지가 떠서 비율이 깨졌습니다.
강제 새로고침(⌘⇧R) 전까지 드러나지 않습니다.

```
public/promo/gift-2026q4.png     ← 기존
public/promo/gift-2026q5.png     ← 교체할 때는 이렇게 새 이름으로
```

설정값의 `desktop`/`mobile` 경로도 함께 바꾸면 됩니다.
파일명을 바꾸기 어렵다면 최소한 **배포 후 강제 새로고침으로 직접 확인**하세요.

## 반드시 지킬 것

1. **근거 없는 수치를 이미지에 넣지 않는다.** "최대 ○○만원", "○○% 보상",
   "업계 1위" 같은 표현은 객관적 근거가 없으면 표시광고법 위반 소지가 있다.
   사은품 금액은 상품별 근거가 확보되기 전까지 이미지에 박지 않는다.
2. **통신사 공식 로고(CI)를 넣지 않는다.** 상표 사용 권한이 없다.
3. **레퍼런스 사이트의 문구·이미지를 복제하지 않는다** (CLAUDE.md 규칙 5).
4. **보유하지 않은 수상·인증 표기 금지.** "○○ 대상 수상", "국가 공인기관 인증" 등.

## 슬롯이 비어 있으면

`PROMO_IMAGES` 가 빈 배열이면 **섹션 자체가 렌더링되지 않는다.** 빈 여백이 생기지 않으니
이미지가 준비되기 전까지 그대로 두면 된다.
